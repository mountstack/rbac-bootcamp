# RBAC System - Teaching Backend API
**Author:** Rijwan Hossain

A production-ready teaching project designed to help students master **Role-Based Access Control (RBAC)**, authentication, and database seeding in a Node.js & MongoDB environment.

---

## 🧰 Stack

- **Framework**: Express.js 
- **Language**: JavaScript
- **Database**: MongoDB
- **ORM**: Mongoose
- **Auth**: JWT (JSON Web Token)
- **Security**: bcryptjs
- **Utils**: concurrently, colors, nodemon

---

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have the following installed:
* **Node.js** (v18+)
* **MongoDB** (Local instance)
* **npm** (comes with Node)

### 2. Installation
Clone the project and install the necessary packages:
```bash
git clone <repository-url>
cd rbac-system
npm install
```

### 3. Start the application with seeding 
```bash
npm run dev
```
